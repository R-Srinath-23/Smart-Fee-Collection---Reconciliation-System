### 5. Debugging & Transparency

- **AI Output That Was Wrong:**  
  Placing interactive event handlers (`onMouseEnter`/`onMouseLeave`) directly inside the Server Component `layout.tsx`, causing a Next.js App Router runtime crash.

- **How I Identified the Problem:**  
  Running `npm run dev` and observing the Next.js runtime error in the browser:  
  `"Event handlers cannot be passed to Client Component props."`

- **How I Fixed It:**  
  Moved the interactive sidebar logic out of `layout.tsx` into a separate `"use client"` component (`Sidebar.tsx`) and imported it cleanly into the root layout.
